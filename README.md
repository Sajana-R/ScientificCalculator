
# Scientific Calculator

A scientific calculator developed using C++.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Power
- Square root
- Sine
- Cosine
- Tangent
- Natural logarithm
- Common logarithm
- Exponential

## Project Structure

- `main.cpp` - Main program and menu
- `Calculator.cpp` - Calculator function implementations
- `Calculator.h` - Class declaration
- `Makefile` - Compiles the project

make
